# Instituto del Agua · UCCuyo

Sitio institucional del **Instituto del Agua** (Facultad de Ciencias Químicas y Tecnológicas, Universidad Católica de Cuyo).

Publicado en GitHub Pages junto al Observatorio de IA:

**https://claudiomlarrea.github.io/observatorio-ia/instituto-del-agua/**

## Contenido inicial

- Página de inicio (misma estructura visual que Observatorio / Secretaría: verde institucional + rojo UCCuyo)
- **Plan AURA** como botón principal
- Convocatoria a proyectos de investigación y extensión
- Documentos (resoluciones 418, 767, 849 y planificación 2026)

## Desarrollo local

Abrir `index.html` o servir la carpeta:

```bash
cd instituto-del-agua
python3 -m http.server 8765
```

Luego visitar `http://localhost:8765/`.
