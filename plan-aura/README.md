# Plan AURA · UCCuyo

Sitio institucional del **Plan Integral AURA** (Universidad Católica de Cuyo).

Publicado en GitHub Pages junto al Observatorio de IA:

**Sitio (URL institucional):** https://observatorio-ia.uccuyo.edu.ar/plan-aura/

(Hosting técnico en GitHub Pages; el enlace público a usar es el de UCCuyo.)

## Contenido inicial

- Página de inicio (misma estructura visual que Instituto del Agua / Observatorio)
- Plan AURA como mandante, dependiente de la UCCuyo
- Convocatoria a proyectos de investigación y extensión
- Documentos (resoluciones 418, 767, 849 y planificación 2026)
- Contacto: Director del Plan AURA · Ing. Luis Jiménez

## Desarrollo local

```bash
cd plan-aura
python3 -m http.server 8766
```

Luego visitar `http://localhost:8766/`.
