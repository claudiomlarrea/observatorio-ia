# Reparar panel de carga (si ves código al guardar)

Si al guardar aparece texto con panel-carga.html?saved=1:
→ la implementación web TODAVÍA es la versión vieja.
→ Igual el guardado suele haber funcionado (revisá la planilla).

## Cómo saber si ya está actualizado
Al abrir el panel debe verse el sello verde **Panel v4** al lado del título.
Si no está, la web sigue sirviendo código viejo.

## Pasos (obligatorio: Nueva versión)
1. script.google.com → proyecto Publicaciones Página Web
2. Pegá TODO PublicacionesWeb.gs del repo (Cmd+A / Cmd+C / Cmd+V) → Guardar
3. Implementar → Administrar implementaciones → ícono lápiz
4. Versión: **Nueva versión** (no “Usar versión anterior”)
5. Implementar
6. Cerrá pestañas viejas del panel y abrí de nuevo desde el Observatorio

Si solo guardás el .gs sin “Nueva versión”, el /exec sigue con el código viejo.
