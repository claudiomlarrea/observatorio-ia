Programa automático desde Drive + editor del equipo
===================================================

Objetivo
--------
Cuando un investigador sube un artículo o un PowerPoint a las carpetas Drive,
el sistema:

  1. Manda el mail a Investigación
  2. Regenera los catálogos PDF
  3. Actualiza el PROGRAMA del sitio (#jornadas-ia)  [si no está en modo manual]
  4. Actualiza la AGENDA de la app (jornadas-ia-2026/)

Además, el equipo puede editar el programa a mano (alta / baja / reorden)
con login Google y lista blanca de correos.

Dos implementaciones web (obligatorio)
--------------------------------------
No mezclar editor y API pública en la misma implementación.

  A) API pública (sitio / programa / catálogos)
     URL: la de CATALOGOS_API_URL en js/jornadas-config.js
     Ejecutar como: Yo (investigacion@…)
     Quién tiene acceso: Cualquier usuario

  B) Editor del programa (equipo)
     URL: PROGRAMA_EDITOR_URL en js/jornadas-config.js
       …/exec?action=editar_programa
     Ejecutar como: Usuario que accede a la aplicación web
     Quién tiene acceso: Cualquier usuario de una cuenta de Google

En B, Google pide login y Session.getActiveUser() devuelve el correo.
Si la API pública queda en «Usuario que accede», el sitio no puede
leer el programa y cae al JSON de respaldo.

Cómo se arman las ponencias (modo automático)
---------------------------------------------
- Apertura e indicaciones fijas (15:00–15:25)
- Una ponencia por apellido detectado en los nombres
  Area_Universidad_Apellido_Titulo…
- Orden alfabético por apellido
- Turnos de 10 minutos desde 15:25
- Estado “Provisional” hasta confirmar en el panel


Sitio / agenda / PDF
--------------------
- Listado web (#jornadas-ia) y app (jornadas-ia-2026/): leen la API
  (?action=programa / programa_agenda). Tras Guardar en el editor,
  Cmd+Shift+R en el sitio y en la app (la app también tiene SW).
- PDF «Abrir programa»: archivo estático en
  assets/jornadas/programa-jornadas-ia-2026.pdf
  No se regenera solo. Tras editar el programa:

    python3 scripts/generate_programa_jornadas_pdf.py
    # (usa data/jornadas-programa-2026.json; sincronizá ese JSON
    #  desde ?action=programa si hace falta)
    # bump ?v= en index.html y commit/push
