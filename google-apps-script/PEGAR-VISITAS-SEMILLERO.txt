PARCHE — Visitas Semillero de IA (site=semillero)
=================================================

El frontend de Jose (sia-uccuyo) debe usar SITE: "semillero".
Hay que publicar una nueva versión de Apps Script o el mapa
responderá {"ok":false,"error":"invalid_site"}.

1. Abrí en Cursor:
   google-apps-script/PublicacionesWeb.gs
2. Cmd+A → copiar
3. Proyecto Apps Script «Publicaciones Página Web»
4. Pegá sobre el .gs de visitas/publicaciones → Guardar
5. Implementar → Administrar implementaciones → lápiz (/exec)
   → Nueva versión → Implementar

Probar:
  .../exec?action=visit&site=semillero
  .../exec?action=visitgeo&site=semillero&country=AR&countryName=Argentina&region=San%20Juan
  .../exec?action=visitmap&site=semillero

Luego (cuando José publique el frontend):
  https://jose2026-market.github.io/sia-uccuyo/#visitas

No afecta los contadores observatorio / secretaria / agua / aura.
