PARCHE RÁPIDO — Visitas Secretaría (1 minuto)
==============================================

Diagnóstico (ya verificado): el script PUBLICADO responde
  {"ok":false,"error":"invalid_site"}
cuando site=secretaria. Por eso el Observatorio suma y la Secretaría no.

Cuenta: investigacion@uccuyo.edu.ar
Proyecto: Publicaciones Página Web

Opción A — Parche mínimo (si ya pegaste visitgeo antes)
------------------------------------------------------
1. En PublicacionesWeb.gs buscá la función registrarVisitaGeo_
2. Cambiá ESTA línea:

   if (site !== "observatorio") {

   por:

   if (site !== "observatorio" && site !== "secretaria") {

3. Implementar → Administrar implementaciones → lápiz (la de /exec)
   → Nueva versión → Implementar

Opción B — Pegar archivo completo (recomendado)
----------------------------------------------
1. Abrí en Cursor:
   observatorio-ia/google-apps-script/PublicacionesWeb.gs
2. Cmd+A → copiar
3. En Apps Script: PublicacionesWeb.gs → Cmd+A → borrar → pegar
4. Implementar → Nueva versión → Implementar

Probar en el navegador (debe decir ok:true):
  .../exec?action=visitgeo&site=secretaria&country=AR&countryName=Argentina&region=San%20Juan

Luego recargá:
  https://claudiomlarrea.github.io/secretaria-investigacion/#visitas
