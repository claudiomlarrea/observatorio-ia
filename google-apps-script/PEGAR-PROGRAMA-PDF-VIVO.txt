PDF del programa — siempre al día
=================================

El botón «Abrir programa (PDF)» abre:

  https://observatorio-ia.uccuyo.edu.ar/jornadas-programa-pdf.html

Esa página lee la misma API que el listado (?action=programa).
Para bajar un PDF: botón «Imprimir / Guardar PDF» del navegador
(Destino: Guardar como PDF).

El archivo assets/jornadas/programa-jornadas-ia-2026.pdf es solo
respaldo y puede quedar viejo; no hace falta republicarlo cada vez
que se reordena el programa.
