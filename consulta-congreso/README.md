# Consulta Académica

App del Observatorio de IA para **congresos, jornadas, talleres y otras reuniones científicas**.

## Oferta pública
El Observatorio **arma la app por evento** (programa, logo, PDF) y entrega la URL lista para compartir.
La demo pública está en `/consulta-congreso/`.

## Herramienta interna
`/consulta-congreso/cargar.html` es de uso interno del Observatorio (Excel / JSON / PDF).

## URLs
- Demo: `/consulta-congreso/`
- Carga interna: `/consulta-congreso/cargar.html`
- Instalar: `/consulta-congreso/instalar.html`

## Formato del programa
Ver `data/evento.ejemplo.json` y `data/evento.radu-larioja-2026.json`.

También se pueden importar planillas Excel (formatos CH / CS) desde la herramienta interna.
